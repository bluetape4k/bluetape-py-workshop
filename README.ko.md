# bluetape-py-workshop

[English](README.md) | 한국어

[`bluetape-py`](https://github.com/bluetape4k/bluetape-py)를 활용한 실행 가능한
Python 백엔드 서비스 예제 저장소입니다.

먼저 로드맵을 확정한 뒤 구현을 시작합니다. 첫 Epic과 하위 이슈에서는 현재 사용할
수 있는 `bluetape-py` 패키지를 애플리케이션 형태의 예제로 구성하고, 아직 개발 중인
기능은 명시적인 도입 조건과 함께 관리합니다.

아직 예제 구현은 시작하지 않았습니다. 승인된 학습 경로와 의존 순서는 저장소
이슈에서 확인할 수 있습니다.
