# bluetape-py-workshop

English | [한국어](README.ko.md)

Runnable Python backend service examples using
[`bluetape-py`](https://github.com/bluetape4k/bluetape-py).

The repository is being initialized roadmap-first. Its first Epic and focused
issues will define application-shaped examples for the currently available
`bluetape-py` packages and explicit adoption gates for planned capabilities.

Implementation has not started yet. Follow the repository issues for the
approved learning path and dependency order.
